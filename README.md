# Pet Feeder Scheduler for Home Assistant

Write an on-device feeding schedule to an **Aqara Pet Feeder C1** paired with
Home Assistant's built-in **ZHA** integration, so meals keep coming even when
Home Assistant or your internet is down.

> **Status: under review.** The first implementation is in an open pull request
> and has not been merged yet. Don't install it until it lands on `main`.

## AI-written code

The code and docs in this repository were written by an AI assistant (Claude,
by Anthropic) working with the repository owner, and are being reviewed by
humans before release. Every change goes through a pull request so it can be
read line by line. Please review it with that in mind.
